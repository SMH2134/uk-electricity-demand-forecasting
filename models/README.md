# Saved Models

This folder stores trained model files generated by running `src/main.py`.

## Files generated after training

| File | Description |
|------|-------------|
| `best_lstm_model.h5` | Trained LSTM model weights (TensorFlow/Keras) |
| `preprocessing.pkl` | Fitted StandardScaler used for feature normalisation |
| `preprocessing_metadata.pkl` | Metadata about the preprocessing pipeline |

## Why these are not in the repository

Model files are binary and large (typically 10-100MB). GitHub recommends keeping repositories under 100MB. To use these models:

1. Run `python src/main.py` to train and generate them locally
2. The script saves them automatically to this folder

## Dataset required

Download `demanddata_2024.csv` from the National Grid's public data portal and place it in the root directory before running.
